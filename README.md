# CTFs Writeups

Personal archive of reverse engineering CTF challenges I've solved, binaries, crackmes, and assembly puzzles.

## Structure

```
Platform/
└── Challenge_Name/
    ├── challenge/    # original files
    └── sol/          # writeup + solve script
```

## What's inside

Each solution folder contains a `solve.md` writeup explaining the approach, and a `solve.py` script when applicable.

Platforms covered so far: **CyberTalents**,... OR Hackathons like: **Hackअस्त्र**, **THEM?!CTF**, and more added over time.

## Tools I use

`ghidra` · `gdb` · `Cutter` · `AvaloniailSpy` / `pwndbg` · `python` · `strings` · `objdump` · `file`

---

> All challenges are from authorized CTF platforms and solved for learning purposes.
